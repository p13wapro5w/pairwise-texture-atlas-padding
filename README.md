# pairwise-texture-atlas-padding

角色换装后，袖口和靴子边缘渗出一圈别的颜色，图集里相邻子图之间没留 padding，mip 第 3 级开始直接采样到邻居；子图按 NPOT 尺寸摆放，压缩块按 4x4 对齐后实际占用比声明的大，越界写进隔壁；采样用的是 clamp，子图内部 UV 到边界的插值仍然跨出去；图集每帧重新打包，已上传的纹理区域和 UV 偏移对不上；流式加载只换了子图，图集整体的 mip 链没重建，远处仍是旧内容；各向异性过滤在子图边界沿长轴采样，采样点落到邻居；旋转打包后 UV 没同步旋转，贴图方向错了 90 度；压缩格式按整图集选择，带 alpha 的子图 forcing 成不透明块；子图缩放时按 2 的幂取整，细长装饰条被拉扁；图集扩容后旧句柄失效，材质仍指向旧纹理。render/texture_atlas_padding.py 是核心，tests/test_texture_atlas_padding.py 15个红。要修的是：子图外扩 padding；按块对齐占位；UV 内缩半像素；重打包同步偏移；换页重建 mip；各向异性限制在子图内；旋转同步 UV；按子图选格式；缩放保持宽高比；扩容刷新句柄。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
